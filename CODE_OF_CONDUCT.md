# Code of conduct

Everyone participating in this project's issues, pull requests and discussions
is expected to treat others with respect.

## Expected behavior

- Be constructive and specific. Critique ideas and code rather than people.
- Welcome questions and differing experience levels.
- Respect privacy, personal boundaries and requests to stop a conversation.
- Accept feedback and correct mistakes without personal attacks.

Harassment, threats, discriminatory or sexual remarks, doxxing, spam and repeated
disruption are not acceptable.

## Reporting and enforcement

The repository maintainer is [@luckeyfaraday](https://github.com/luckeyfaraday).
Use GitHub's report-content controls for abusive public content. For a concern
requiring private discussion, ask the maintainer for a private contact channel
without posting personal information or the sensitive details.

Maintainers may edit or remove contributions, lock conversations, issue warnings
or restrict participation according to the severity and repetition of the
behavior. Reports should be handled discreetly; retaliation for a good-faith
report is unacceptable. If a report concerns the maintainer or cannot be handled
within the project, use [GitHub's abuse reporting](https://github.com/contact/report-abuse).
