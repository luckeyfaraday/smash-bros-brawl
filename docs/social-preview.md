# Social preview artwork

The homepage at <https://brawl.luckeysystems.com/> uses
`public/social/brawl-social-v1.png` for its shared-link artwork. The metadata is
in the initial HTML, including the canonical URL, Open Graph title, description,
image dimensions/type/alt text, and an X `summary_large_image` card. The image is
a standalone public file; no JavaScript or authentication is needed to fetch it.
The final PNG is 1730 × 909 pixels (approximately 1.91:1) and 2,547,708 bytes.
Its original generated bytes are preserved, and the metadata uses those actual
dimensions rather than the dimensions requested in the prompt.

The Open Graph fields follow the [Open Graph protocol](https://ogp.me/).
Use the [deployment workflow](deployment.md) to publish the HTML and artwork
together. A local build or Git push alone does not update the live site.

## Verification

After deployment, fetch the homepage using `Twitterbot` and `Discordbot` user
agents. Check that the HTML contains a single set of preview tags and that the
absolute image URL returns status 200 with an image content type. Confirm the
image's real dimensions match the metadata and its size is below 5 MB. An HTTP
crawler check verifies the published inputs; it does not confirm how a specific
post renders inside a social platform.

Social platforms can cache earlier previews. Use a new filename for replacement
artwork and update all image references in `index.html`. Existing posts may
continue to show their cached cards.

## Generation

Created with the built-in image generation tool. This is original promotional
arena artwork, not a gameplay screenshot. The final generation prompt was:

```text
Use case: ads-marketing
Asset type: social-sharing preview image for the browser game Brawl Browser Lab.
Create one finished 1200x630 landscape social card with striking, original sci-fi arena artwork and very legible typography.
An empty, original futuristic steel fighting platform floats above luminous deep-violet clouds and a blue-black starfield. Its geometric metal deck has crisp cyan light strips, warm orange light on the left edge, and blue rim light on the right. A narrow burst of pale light rises behind it. Keep the platform in the lower third, with enough atmospheric negative space for the headline. Beautiful cinematic game-poster illustration, detailed brushed metal, atmospheric depth, restrained particles, rich indigo palette.
The central upper half features the exact word "BRAWL" in extremely large, bold, forward-slanted brushed-silver display lettering. Above it, a modest white uppercase label reads exactly "BROWSER LAB". Below the main title a clean, bold white uppercase subtitle reads exactly "PLAY IN YOUR BROWSER". Near the bottom, a small but clearly legible line reads exactly "brawl.luckeysystems.com".
Keep all text at least 70 pixels away from the canvas edges. Make the main title dominant and immediately readable at 400 pixels wide. Intentional premium typography and balanced composition. Full bleed background.
Only original environment artwork: no characters, people, mascots, third-party logos, corporate branding, interface HUD, social-media icons, watermarks or outer border. Render only the four exact text strings specified.
```
